# Планировщик выходных в Уфе: данные

Данные для сервиса подбора маршрута выходного дня в Уфе. Все цены указаны на одного человека в рублях, по ценам осени 2026 года. Координаты мест — в системе WGS84 (широта, долгота).

## Таблицы для сервиса

По ним алгоритм строит граф мест (вершины — заведения, рёбра — расстояние/время между координатами) и подбирает оптимальный маршрут под предпочтения пользователя на 2 часа или на весь день.

**ufa_venues.csv**: места отдыха — вершины графа маршрута.

- `id` : уникальный номер места;
- `name` : название заведения;
- `category` : тип активности (`restaurant`, `museum`, `park`, `spa`, `cinema`, `mall`, `landmark`, `sport`, `entertainment`) — по нему фильтрится запрос пользователя;
- `latitude` , `longitude` : координаты места на карте;
- `avg_check_rub` : средний чек на одного человека (для оценки бюджета маршрута);
- `rating` : оценка посетителей по шкале 0–5 (вес вершины при ранжировании).

**ufa_metrics.csv**: справочные метрики — обоснование спроса, рынка и экономики проекта.

- `category` : область показателя (`demographics`, `infrastructure`, `user_behavior`, `tourism`, `monetization`, `costs`);
- `metric` : название показателя (например, `total_population_ufa`, `avg_planning_time`, `freemium_price`);
- `value` : числовое значение;
- `unit` : единица измерения (`people`, `objects`, `hours`, `percent`, `rub`, `rub_per_month`).

**ufa_data.json**: тот же набор данных в едином JSON-дампе — для загрузки в код без парсинга CSV.

- `demographics` : население Уфы и целевой аудитории;
- `infrastructure_summary` : количество объектов досуга по категориям;
- `venues_sample` : список мест (аналог `ufa_venues.csv`);
- `user_behavior` : как горожане планируют выходные сейчас (время, источники, неудовлетворённость, средний чек);
- `tourism` : турпоток и бюджет туриста;
- `monetization_and_costs` : потоки дохода и затраты на разработку/поддержку.

*Файлы CSV разделены точкой с запятой (`;`) и сохранены в UTF-8 с BOM — корректно открываются в Excel и читаются `pandas.read_csv(sep=';')`. JSON — в UTF-8 без BOM.*
